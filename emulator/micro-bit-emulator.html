Programm aus MakeCode (JavaScript-Ansicht) einfügen und auf Start drücken. Die Tasten funktionieren, solange das Textfeld nicht aktiv ist. Der Ton startet mit dem ersten Klick auf Start. Paste a program from MakeCode's JavaScript view and press Run. The keys work while the text box isn't active. Sound starts with the first click on Run.
